# TimeScore 项目深度分析报告

## 一、核心机制诊断

### 1.1 分数计算公式分析

**当前公式**（ScoringViewModel.swift）：

```
final_score = base_score × duration × energy_coeff × combo_coeff × start_bonus × novice_bonus
```

**等级配置**：

| 等级 | 基础分/分钟 | 精力消耗/分钟 | 场景 |
| --- | --- | --- | --- |
| S | 1.8 | 0.35 | 深度学习、创意突破 |
| A | 1.2 | 0.25 | 项目工作、编程 |
| B | 0.7 | 0.18 | 邮件、会议 |
| C | -0.5 | 0.10 | 刷手机、拖延 |
| D | -1.0 | 0.15 | 熬夜、暴饮暴食 |
| R1-R3 | 0.2-0.4 | -0.10~-0.30 | 恢复精力 |

**🔴 发现的问题**：

| 问题 | 影响 | 建议 |
| --- | --- | --- |
| **S级精力消耗过高** | 35%×60分钟=21点，120满精力只能做5.7小时 | 降至0.25，与价值匹配 |
| **C/D惩罚过轻** | -0.5~-1.0对比S级1.8，**惩罚不足50%** | C改为-0.8，D改为-1.5 |
| **R级收益过高** | R3休息30分钟赚12分，可能超过B级工作 | R级不加分，仅恢复精力 |
| **缺少时间衰减** | 连续工作4小时和1小时同效率，不合理 | 增加连续时长惩罚系数 |

### 1.2 精力系统设计

**当前机制**：

- 最大120，默认100
- 自动恢复：闲置30分钟后，每分钟+0.02（即每小时+1.2）
- 工作消耗：按等级配置

**🔴 关键缺陷**：

| 缺陷 | 说明 | 修复方案 |
| --- | --- | --- |
| **恢复过慢** | 从0到满需要(120/1.2)=100小时=4天 | 提高到每小时+5（睡一晚恢复40点） |
| **无睡眠重置** | 代码有每日重置但只重置到100 | 睡眠后应完全恢复+额外奖励 |
| **缺少透支机制** | 精力<0应可继续但效率暴跌 | 增加"透支模式"：精力<0时系数=0.3 |

### 1.3 推荐优化后的公式

```swift
// 新公式
final_score = base_score × duration × energy_coeff × fatigue_coeff × start_bonus

// 疲劳系数（新增）
fatigue_coeff = 1.0 - (continuous_work_minutes / 240) * 0.3  // 每4小时效率降30%

// 精力系数优化
if energy < 0 {  // 透支
    coeff = 0.3 + (energy + 30) / 100  // -30精力时0.3，0精力时0.6
} else if energy < 30 {
    coeff = 0.6 + energy / 75
} else if energy < 70 {
    coeff = 1.0
} else {
    coeff = 1.0 + (energy - 70) / 100
}
```

## 二、苹果开发者申请与上线流程

### 2.1 开发者账号申请（已简化）

**步骤**：

1. 访问 [Apple Developer](https://developer.apple.com/programs/enroll/)
2. 使用 Apple ID 登录（建议用独立ID）
3. 选择 **Individual**（个人）-$99/年
4. 填写信息：
    - 姓名：林伟豪（与身份证一致）
    - 地址：真实地址
    - 身份证：上传正反面照片
5. 支付 $99（支持支付宝/微信）
6. 等待审核（通常1-3个工作日）

**⚠️ 关键注意**：

- 必须用真实姓名，App Store显示名可后续修改
- 地址用身份证地址，不要填国外
- 支付后保留收据，可抵扣个税

### 2.2 App Store 上架流程

```mermaid
准备阶段 → 开发测试 → 打包上传 → 审核 → 发布
```

| 阶段 | 关键任务 | 预计时间 |
| --- | --- | --- |
| **准备** | App图标(1024×1024)、截图(6.5寸+5.5寸)、描述文案 | 2天 |
| **开发** | 完成核心功能+测试 | 你已接近完成 |
| **打包** | Archive → Upload to App Store | 1小时 |
| **审核** | 苹果审核（首次通常3-5天） | 3-7天 |
| **发布** | 设置价格、地区、关键词 | 1小时 |

**首次上架检查清单**：

- [ ]  App 图标：1024×1024，无透明通道
- [ ]  截图：iPhone 6.5寸（1242×2688）×5张，iPhone 5.5寸×5张
- [ ]  描述文案：中文+英文（如果你只做国内，英文可简写）
- [ ]  隐私政策网页（可用免费服务如 [github.io](http://github.io/)）
- [ ]  测试账号（如果App需要登录）
- [ ]  年龄分级：12+（因为涉及时间管理）

## 五、关键决策点

### 决策1：是否现在申请开发者账号？

**建议：立即申请**，原因：

- 审核需要3-7天
- 你App功能已接近完成
- 早一天上架早一天获得反馈

### 决策2：首版免费还是收费？

**建议：完全免费**，原因：

- 个人开发者首个App，积累口碑比赚钱重要
- 时间管理类App需要用户粘性，免费降低门槛
- 后续可通过Pro版变现

### 决策3：先做国内还是海外？

**建议：国内为主，海外同步**：

- 国内：小红书、即刻、微博（中文内容）
- 海外：Product Hunt、Twitter（英文内容）
- TimeScore 概念全球通用，不冲突
