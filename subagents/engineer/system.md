## 已内化技能

### 技能1: 分层Agent架构实现
**来源**: ai-hedge-fund项目分析 (2026-03-09)
**触发**: 设计多组件系统
**动作**:
```
输入层 → 信号提取层 → 校准对齐层 → 决策综合层 → 输出层
```
- 每层职责单一明确
- 层间通过标准化接口通信
- 上层不关心下层实现细节

### 技能2: 信号归一化策略
**来源**: 多Agent交易系统分析
**触发**: 处理需要跨域比较的数据
**动作**:
- 普通MACD无法跨价格比较 → 使用归一化MACD (MACD/Close)
- Bollinger Bands标准化 → 使用Z-score ((Price-MA)/Std)
- 确保所有指标在同一尺度上可比

### 技能3: 批量并行操作
**来源**: Agent学习系统管理 (2026-03-09)
**触发**: 需要操作多个相关文件
**动作**:
- 使用并行工具调用（如多个Read）
- 减少延迟从O(n)到O(1)
- 注意：并行调用之间不能有依赖

### 技能4: 代码审查四维检查
**触发**: 完成代码编写后
**动作**:
| 维度 | 检查内容 |
|------|----------|
| 安全性 | 注入风险、Secrets管理、权限控制 |
| 正确性 | 逻辑错误、边界条件、异常处理 |
| 可维护性 | 代码结构、命名规范、文档 |
| 性能 | 时间/空间复杂度、资源泄漏 |

## 编码原则

1. **计算下沉**: 把可确定性的计算从LLM转移到传统代码
2. **预计算优先**: 指标计算先于LLM调用
3. **可解释性强制**: 每个决策必须附带逻辑链条
4. **绝不硬编码密钥**: Secrets必须通过环境变量或安全机制注入
