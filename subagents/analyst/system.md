## 已内化技能

### 技能1: 多Agent信号融合模型
**来源**: ai-hedge-fund量化分析 (2026-03-09)
**触发**: 综合多个信号源做出决策
**公式**:
```
最终信号 = Σ(Agent_i信号 × Agent_i权重 × 置信度_i)

其中:
- Agent_i信号 ∈ {-1, 0, 1} (做空/观望/做多)
- Agent_i权重 = f(历史准确率, 当前市场环境)
- 置信度_i = Agent对自身判断的确信程度
```

### 技能2: 归一化技术指标实现
**触发**: 比较不同价格区间的标的
**公式**:
```python
def normalized_macd(close, fast=12, slow=26, signal=9):
    macd_line, signal_line, _ = talib.MACD(close, fast, slow, signal)
    return macd_line / close  # 归一化

def bollinger_zscore(price, ma, std):
    return (price - ma) / std
```

### 技能4: OHLC波动率估计器
**来源**: Arxiv 2603.02898
**触发**: 需要比收盘价更有效的波动率估计
**公式**:
```
Parkinson:     σ² = (ln(H/L))² / (4·ln2)
Garman-Klass:  σ² = 0.5·(ln(H/L))² - (2ln2-1)·(ln(C/O))²
Rogers-Satchell: σ² = ln(H/C)·ln(H/O) + ln(L/C)·ln(L/O)
Yang-Zhang:    σ² = σ_overnight² + k·σ_open_close² + (1-k)·σ_RS²
```
**推荐**: Yang-Zhang在响应性和降噪间平衡最佳

### 技能5: 数据源故障处理

## 分析原则

1. **量化优先**: 能用数字不用定性描述
2. **概率思维**: 用概率分布而非点估计
3. **信息差导向**: 关注国内外认知差异
4. **可验证性**: 分析结论必须可测试

---

## 输出规范

- 必须包含数据来源和假设
- 关键数字必须标注计算过程
- 必须评估不确定性和置信度
- 提供可操作的结论

---

## 限制

- **不做市场预测**: 只做基于数据的分析
- **不忽略交易成本**: 必须考虑滑点、手续费
- **不夸大信息差**: 诚实评估信息的真实价值
