## 2026-03-05 (Thursday)

### 📚 今日精选

**作者**: Shane Parrish (引用 Charlie Munger)  
**学习时长**: 12分钟

---

### 🎯 核心主题
**冲浪式创新：识别并驾驭技术与经济浪潮**

在经济快速演变的时代，技术浪潮不断形成、 cresting 然后破碎。关键不是更努力地工作，而是培养早期发现新兴浪潮的洞察力、在别人认识到潜力之前划向它们的勇气，以及在恰当时机站起来的技巧。

---

### 💡 关键洞察

**Charlie Munger 的"冲浪模型" (Surfing Model)**

> "当技术在我们这样的文明中快速发展时，你会得到一个我称之为'竞争性毁灭'的现象。你有最好的马车鞭工厂，突然间，这匹无马马车进来了。没过几年，你的马车鞭生意就死了。你要么进入不同的行业，要么就死了——被毁灭了。这发生了一次又一次。
>
> 当这些新业务进来时，先行者拥有巨大优势。有一个我称之为冲浪的模型——当一个冲浪者站起来抓住浪潮并停留在那里时，他可以走很长很长的路。但如果他从浪潮上下来，他就会陷入浅滩。"

**历史案例**

| 公司/行业 | 浪潮 | 结果 |
|-----------|------|------|
| **Kodak** | 1975年发明了数码相机，但紧抱胶片业务 | 错过数字浪潮，最终破产 |
| **马车鞭制造商** | 汽车取代马车 | 行业被彻底毁灭 |
| **音像租赁店** | 流媒体服务兴起 | 被 Netflix 等颠覆 |
| **出租车牌照** | 网约车 (Uber/Lyft) | 曾价值百万的牌照变得几乎一文不值 |

**核心洞察**
1. **先行者获得不成比例的回报** - 早期掌握新范式的人不仅成功，往往还能主导市场
2. **错过浪潮 = 陷入浅滩** - 错过浪潮或过早下船的人只能在旁观他人乘势而上
3. **竞争毁灭是常态** - 技术快速迭代中，旧模式被摧毁是不可避免的

**核心主题**: **身份认同改变 - 从"我要做"到"我是"**

---

### 🎯 关键洞察

**身份认同理论 (Identity-Based Habits)**

> "你不会达到目标的高度，你会跌落到系统的水平。"
> "你的每一个行动都是在给想成为的人投票。"

**核心转变**
- 不是"我要戒烟"，而是"我不是烟民"
- 不是"我要跑步"，而是"我是跑者"
- 不是"我要投资"，而是"我是投资者"
- 不是"我要创作"，而是"我是创作者"

**为什么身份改变比目标设定更有效**
1. **目标导向的问题** - 目标一旦达成，动力消失；身份是持续的状态
2. **行为与身份的一致性** - 人们总是按照自己认同的身份行事
3. **复利效应** - 每天1%进步，一年后提升37倍

**两分钟规则**
- 任何习惯都可以缩减为两分钟的版本
- "每晚睡前阅读" → "读一页"
- "做30分钟瑜伽" → "拿出瑜伽垫"
- **核心**: 先建立习惯，再优化习惯

---

### 🧠 可应用思维模型

**1. 身份投票框架 (Identity Voting Framework)**
- 每个行动都是给"想成为的人"投一票
- 积累足够多的投票，新身份就自然形成
- 问：这个行动是在给哪个身份投票？

**2. 习惯复利计算器 (Habit Compounding)**
- 每天进步1% → 一年后37倍提升
- 每天退步1% → 一年后几乎归零
- 微小习惯 × 时间 = 巨大改变

**3. 两分钟启动法 (Two-Minute Rule)**
- 降低启动门槛到2分钟内可完成
- 先建立行为模式，再追求强度/时长
- 完成比完美更重要

---

### 🎓 与2026目标的关联

**财富增长** (股票账户至十万)

| 行动类型 | 权重 | 示例 |
|----------|------|------|

- **减少摩擦**：把学习资料放在触手可及的地方
- **增加诱惑**：把需要避免的东西放在难以触及的地方
- **视觉提醒**：让目标身份可见（如桌面壁纸、便签）

**3. 两分钟规则实战**

任何习惯都可以缩减为两分钟的版本：

| 学习量化投资 | 看一个概念定义 |
| 写技术博客 | 写一句话大纲 |

**核心逻辑**：先建立行为模式，再优化强度。完成比完美重要。

### 🎯 核心主题
**OODA Loop：战斗机飞行员的快速决策框架**

OODA代表 Observe（观察）→ Orient（判断）→ Decide（决策）→ Act（行动）。由战斗机飞行员John Boyd开发，被美军广泛应用于空战和军事战略。

**核心洞察**: 决策速度决定胜负。更快完成OODA循环的一方获得决定性优势。

---

### 💡 关键洞察

**1. OODA四个阶段**

| 阶段 | 目标 | 关键问题 |
|------|------|----------|
| **Observe** | 收集信息 | 发生了什么？ |
| **Orient** | 分析理解 | 意味着什么？ |
| **Decide** | 做出决策 | 要做什么？ |
| **Act** | 执行行动 | 立即执行 |

**2. Orient是最关键的一步**

Boyd认为Orient阶段决定决策质量。影响因素：
- **文化**: 背景如何影响解读
- **经验**: 过去类似情况
- **新信息**: 当前数据的独特性
- **分析**: 逻辑推理过程

**3. 比对手更快=赢**

空战中，更快完成OODA循环的飞行员可以：
- 预判对手动作
- 占据有利位置
- 在对手还在"观察"时已经"行动"

**4. 与72小时决策法则结合**

```
OODA Loop (微观战术)     72小时法则 (宏观战略)
    ↓                        ↓
5分钟完成决策          +   72小时内战略转向
高频迭代                    把握浪潮时机
```

### 🧠 可应用框架

**快速定向技巧**:
```
问题1: 这是什么类型的情况？
  → 趋势延续/趋势反转/震荡/突发事件

问题2: 类似情况过去如何发展？
  → 回忆3个类似案例

问题3: 这次有什么不同？
  → 识别当前情况的独特性

问题4: 我的判断是什么？
  → 做出方向性判断
```

**加速OODA的技巧**:
1. **预设计触发器**: 提前定义条件，减少决策时间
2. **建立决策模式库**: 常见情况的快速决策模板
3. **时间限制**: Observe(2min) → Orient(3min) → Decide(1min) → Act(立即)

### 🎯 应用场景

**交易决策**:
```
[Observe] 持仓股票突然下跌5%
- 价格、成交量、新闻、大盘

[Orient] 这是公司特定问题还是系统性风险？
- 基本面受损还是技术性调整？

[Decide] 立即减仓50%，剩余设止损

[Act] 执行卖出，调整止损单
```

**产品开发**:
```
[Observe] 用户反馈新功能不受欢迎

[Orient] 是功能问题还是实现问题？

[Decide] 暂停推广，A/B测试改进版

[Act] 下线入口，开始改进版本
```

### ⚠️ 常见错误

1. **分析瘫痪**: 在Orient阶段停留太久，追求完美信息
2. **过早行动**: 跳过Orient直接行动
3. **忽略反馈**: 行动后不观察结果
4. **固守认知**: 拒绝根据新信息调整判断
