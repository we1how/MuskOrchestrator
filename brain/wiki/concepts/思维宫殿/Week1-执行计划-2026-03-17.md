# Week 1 执行计划（2026-03-17 开始）

> **目标**: 原则层改造 - 让4个新原则成为本能
> **投入**: 每天30-60分钟
> **核心**: 刻意调用原则，而非被动阅读

---

## 🎯 Week 1 目标

```
Day 1-2: 学习4原则，制作速查卡
Day 3-4: 设计触发器，贴到显眼位置
Day 5-7: 每天刻意调用1个原则，记录效果

Week 1 成功标准:
□ 能不看材料说出4个原则的核心内容
□ 至少调用了每个原则1次
□ 形成了晨间+晚间仪式习惯
□ 连续7天完成最低限度目标
```

### Day 2 - 设计触发器

**时间投入**: 45分钟

**任务**:
1. **晨间仪式**（5分钟）
   - 填写今日仪式模板
   - 预判今天可能需要什么原则

2. **为每个原则设计触发器**（30分钟）

   **原则1：5-Why本质挖掘法**
   ```
   触发器设计:
   □ 手机上设置"重要决策检查清单"快捷指令
   □ 钱包里放一张卡片：">5000元？>3个月？→ 用5-Why"
   □ 电脑桌面便签："重要决策前，先问5个Why"
   ```

   **原则2：72小时产出法则**
   ```
   触发器设计:
   □ 阅读/学习后立即设置72小时倒计时（手机定时器）
   □ Notion模板："阅读记录 + 72小时产出承诺"
   □ 浏览器书签栏："看完这个，72小时内要产出什么？"
   ```

   **原则3：10-10-10情绪冷却法**
   ```
   触发器设计:
   □ 手机锁屏壁纸："情绪来了？等待10分钟"
   □ 手环/手表设置：情绪波动时震动提醒
   □ 办公桌贴纸："10-10-10？"
   ```

   **原则4：问题猎人机制**
   ```
   触发器设计:
   □ 手机22:00闹钟（标签："记录3个问题"）
   □ 床头放问题记录本
   □ 遇到"不对劲"感觉时立即记录的习惯
   ```

3. **物理环境布置**（10分钟）
   - 打印速查卡，贴到工作区域
   - 设置手机壁纸/锁屏提醒
   - 准备问题记录本放床头

**完成标准**:
- [ ] 每个原则都有至少2个触发器
- [ ] 物理环境已布置（贴纸、卡片到位）
- [ ] 手机已设置相关提醒

**产出物**:
- 4个原则的触发器设计方案
- 物理环境布置完成

## ⚠️ 防失败设计

### 如果某天太忙
- 只做最低限度：
  - 晨间仪式（1分钟，只写最重要的决策）
  - 调用1个原则（任何场景，哪怕是选择吃什么）
  - 记录1个问题（最简单的）
  - 量化学习（5分钟）
  - 晚间仪式（1分钟，只打分）

### 如果连续2天未完成
- 立即停下来分析：
  - 是计划太难？→ 降低难度，只保留最核心的
  - 是优先级不够？→ 重新审视这个计划的重要性
  - 是触发器无效？→ 重新设计触发器

### 如果感到疲惫
- 允许只做"最小版本"
- 但不能为0（保持连续性）
- 休息一天后，第二天恢复正常
