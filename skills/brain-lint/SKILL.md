# brain-lint — 第二大脑健康体检

检查 `brain/wiki/` 的结构完整性并给修复建议。

## 检查项
1. **index 缺漏**：`wiki/` 下有但没进 `index.md` 的 `.md` 页面。
2. **坏 wikilink**：`[[X]]` 指向不存在的页面 → 列出（这些是"该补的页面"）。
3. **孤儿页**：没有任何其他页面链接到它的页面。
4. **空/过短页**：内容 < 几行的页面。
5. **raw 积压**：`raw/` 里还没 ingest 的材料。

## 输出
一张体检表（问题类型 | 文件 | 建议动作），并可直接：
- 重新生成 `index.md` 补齐缺漏；
- 列出待建页面清单（坏链目标）供 `/brain-ingest` 时优先补。
