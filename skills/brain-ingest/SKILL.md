# brain-ingest — 把原料整理进第二大脑

把 `brain/wiki/raw/` 的原始材料（或用户当前给的材料）转成结构化 wiki 页面。

## 流程
1. 读 `brain/wiki/index.md` 了解已有结构，避免重复。
2. 对每份材料：
   - **判定归类**：书摘/文章 → `sources/`；思维模型/框架 → `concepts/`；人/组织/工具 → `entities/`；跨主题对比 → `synthesis/`。
   - **提炼**：核心观点（3-5）、对老板的尖锐提问、1-3 个行动项。
   - **交叉引用**：用 `[[页面名]]` 链接相关已有页面（链到还不存在的页面也 OK，标记待补）。
   - 写成 `.md` 存入对应子目录。
3. **更新 `index.md`**：把新页面加进总目录（可重跑 index 生成逻辑）。
4. **追加 `log.md`**：记录本次 ingest（日期 + 处理了什么）。
5. 处理完把 `raw/` 里已消化的原件移走或标记。

## 原则
- 一页一主题，标题用 `# 名称`。
- 链接要慷慨：`[[name]]` 即使目标页还没建，也标记了"值得补"。
- 不复制全文，只留可被复利的精华 + 出处链接。
