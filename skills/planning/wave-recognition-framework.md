## 触发条件

- 感觉"事情越来越难了"
- 行业出现新技术苗头
- 原有优势在衰减
- 职业/投资/技术栈转型决策

---

## 执行步骤

### 1. 建立信号系统
定义你关注的"浪"的指标：
- AI应用增长率
- 新平台用户增速
- 技术社区讨论热度
- 投资回报衰减信号

### 2. 设置触发器
当信号达到阈值时，强制启动评估流程

### 3. 72小时法则
识别到潜在浪头后，**72小时内**必须做出"冲浪/等待"的决策

### 4. 沉没成本剥离
决策时强制问自己：
> "如果我是今天重新开始，我会选择现在的路径吗？"

### 5. 定期复盘
每月回顾：
- 我现在的"浪"还有多久？
- 下一个浪在哪里？

## 可执行模板

### 浪潮评估清单
```
□ 这个浪潮是短期的泡沫还是长期的范式转移？
□ 先行者的优势窗口还有多长？
□ 我是否有足够的资源坚持到浪潮到来？
□ 如果错过这个浪潮，Plan B是什么？
□ 沉没成本是否影响了我的判断？
```

### 决策框架
```
扫描地平线 → 评估浪的质量 → 冲浪/等待决策 → 执行 → 识别浪终点
     ↑                                                    ↓
     └────────────────── 定期复盘 ←───────────────────────┘
```

## 核心洞察

1. **冲浪不是控制，而是顺应**
   - 无法控制浪潮，只能识别浪头、抓住时机

2. **先发优势呈指数级放大**
   - 早一步上浪，获得"看似不公平的优势"

3. **竞争毁灭的残酷性**
   - 柯达1975年发明数码相机，因固守胶片而破产
   - 最危险的不是竞争对手，而是对旧模式的执念
