## 触发条件

使用此技能当：
- 面临重大决策但犹豫不决
- 评估是否应该承担某个风险
- 感觉自信但不确定是"真自信"还是"假自信"
- 需要在"过度悲观"和"过度乐观"之间找到平衡

---

## 核心概念

### 两种自信的本质区别

| 类型 | 来源 | 特征 | 风险 |
|------|------|------|------|
| **虚假自信 (Phony)** | 无知/信息不对称 | 误以为自己懂 | 冒看不见的风险 |
| **专家自信 (Expert)** | 深度熟练/经验 | 真正理解风险 | 经过计算的风险 |

**自测法则**: 如果你需要问自己是哪种，假设是前者，并保留更大的安全边际。

### 风险不对称性矩阵

| 失败成本 | 过度悲观的问题 | 过度乐观的问题 |
|----------|----------------|----------------|
| **低** | 阻止尝试，错过机会 | 可承受，快速学习 |
| **高** | 谨慎是优点 | 鼓励无谓冒险，后果严重 |

## 详细执行步骤

### Step 1: 风险成本评估

**问题清单**:
- 如果失败，最坏情况是什么？
- 失败是否可逆？
- 需要多少资源/时间恢复？
- 对他人的影响有多大？

**分类**:
- **低成本**: 发一封邮件、尝试新工具、主动联系某人
- **高成本**: 大额投资、职业转型、重大承诺

### Step 2: 自信类型诊断

**深度熟练的标志**:
- [ ] 在这个领域有超过100小时的刻意练习
- [ ] 经历过多次失败并从中学习
- [ ] 能清晰解释决策的所有风险点
- [ ] 能教授他人这个领域的核心概念
- [ ] 过去在类似决策中有良好记录

**无知的标志**:
- [ ] 第一次面对这类决策
- [ ] 信息主要来自二手资料
- [ ] 无法清晰解释风险来源
- [ ] 只看到成功看不到失败案例
- [ ] 感到"这应该很简单"

### Step 3: 安全边际设定

```python
def set_margin_of_safety(confidence_type, risk_level):
    """
    基于自信类型和风险级别设定安全边际
    """
    if confidence_type == 'unknown':
        confidence_type = 'phony'  # 默认按虚假自信处理

    base_margin = {
        ('expert', 'low'): 0.1,      # 专家+低风险: 10%缓冲
        ('expert', 'high'): 0.25,    # 专家+高风险: 25%缓冲
        ('phony', 'low'): 0.3,       # 虚假+低风险: 30%缓冲
        ('phony', 'high'): 0.5       # 虚假+高风险: 50%缓冲
    }

    return base_margin.get((confidence_type, risk_level), 0.3)
```

### Step 4: 乐观校准

**低成本场景 - 刻意练习"过度乐观"**:
- 主动承担略高于舒适区的风险
- 设定激进但可达成的目标
- 快速试错，快速学习
- 例子: 主动联系行业大佬、尝试新工具、公开承诺截止日期

**高成本场景 - 谨慎验证**:
- 小规模实验验证假设
- 寻求专家意见
- 准备Plan B和Plan C
- 设置明确的退出条件
- 例子: 大额投资前的小额试水、职业转型前的副业验证

### Step 5: 实力-乐观同步监控

**Carlsen曲线警示**:
```
自信
  ↑
  │      ╱───── 理想状态: 实力追上乐观
  │     ╱
  │    ╱   ← 灾难区: 乐观远超实力
  │   ╱
  │  ╱
  └──────────────→ 时间/经验
```

**监控指标**:
- 决策成功率是否在预期范围内？
- 是否连续出现意外失败？
- 是否有人提醒"你可能过于乐观了"？
- 实际结果是否持续低于预期？

## 应用场景

### 场景1: 投资决策

```
风险成本: 高（可能损失本金）
自信诊断: 第一次投资该类资产 → 虚假自信
安全边际: 50%（单标的不超过总资产5%）
乐观校准: 谨慎验证
  - 先用模拟盘验证策略
  - 小额实盘测试3个月
  - 学习完相关书籍后再加大投入
```

### 场景2: 产品开发决策

```
风险成本: 中（时间机会成本）
自信诊断: 有3个类似项目经验 → 专家自信
安全边际: 25%（预留额外2周缓冲）
乐观校准: 适度乐观
  - 设定激进但可达成的里程碑
  - 每周检查进度
  - 准备功能缩减方案
```

### 场景3: 社交/职业风险

```
风险成本: 低（面子/短暂不适）
自信诊断: 不确定 → 假设虚假自信
安全边际: 30%
乐观校准: 刻意练习过度乐观
  - 直接发邮件给想联系的人
  - 公开承诺目标（利用社会压力）
  - 参加陌生聚会
```

## 与已有技能关联

### 与OODA Loop的结合
- **Orient阶段**: 使用Calculated Confidence评估自身判断可信度
- **Decide阶段**: 基于风险成本决定乐观程度

### 与Chesterton's Fence的结合
- **Chesterton's Fence**: 评估现状时保持谨慎（高成本场景）
- **Winner's Edge**: 决策执行时敢于行动（低成本场景）

### 与Ride the Wave的结合
- **Ride the Wave**: 识别值得投入的趋势
- **Winner's Edge**: 在正确趋势上以赢家姿态行动

## 常见误区

### ❌ "自信就要盲目乐观"
**纠正**: 真正的自信是理解风险后的行动，不是忽视风险

### ❌ "谨慎就是永远不冒险"
**纠正**: 低成本不冒险是错失机会，高成本冒险是愚蠢

### ❌ "等我100%准备好了再行动"
**纠正**: 低成本场景下，70%准备度就行动，边做边学
