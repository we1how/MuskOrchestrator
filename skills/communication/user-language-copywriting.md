# 用户语言文案优化技能

## 描述

将技术产品描述从技术语言转换为用户语言，提升转化率和用户理解度。

## 何时使用

- 撰写产品landing page标题和文案
- 设计产品功能描述
- 准备产品发布材料
- 优化营销邮件主题行
- 撰写App Store/Google Play描述

## 核心原则

### 1. 结果 > 功能 > 技术

```
技术语言                    用户语言
    ↓                          ↓
"OpenClaw instance"    →   "Done in 30 seconds"
"AI-powered engine"    →   "Write 10x faster"
"REST API integration" →   "Connects with your tools"
"Serverless lambda"    →   "Scales automatically"
```

### 2. 具体数字增强说服力

- ✅ "30 seconds" 比 "快速完成" 更有效
- ✅ "13 platforms" 比 "多平台" 更可信
- ✅ "2x revenue" 比 "增加收入" 更有力

### 3. 三层信息架构

有效的落地页信息层次：
```
Layer 1: 结果标题（"Done in 30 seconds"）
Layer 2: 机制副标题（"Publish everywhere from one dashboard"）
Layer 3: 风险消除（"2分钟连接，无需信用卡"）
```

## 执行SOP

### Step 1: 标题测试公式

使用 "After using this, I will ___" 句式验证标题：

- ❌ "After using this, I will have an OpenClaw instance"（无意义）
- ✅ "After using this, I will have published on all my social platforms"（有价值）
- ✅ "After using this, I will have saved 30 minutes"（具体收益）

### Step 2: 技术文案审查清单

发布前检查：
- [ ] 标题是否包含技术术语？
- [ ] 用户是否需要了解技术架构才能理解价值？
- [ ] 是否可以用"结果+时间"替代"技术+功能"？
- [ ] 是否有具体数字增强可信度？
- [ ] 是否回答了"这对我有什么好处"？

### Step 3: A/B测试框架

- 错误做法：这周用A，下周用B
- 正确做法：同时运行A/B，各50%流量
- 原因：消除时间变量（周末vs工作日等）

### Step 4: 竞品文案分析

收集3-5个竞争对手的标题，分类：
- 技术导向型（避免）
- 功能导向型（中等）
- 结果导向型（学习）

## 常见错误

| 错误类型 | 示例 | 修正 |
|---------|------|------|
| 技术堆砌 | "AI-powered cloud-native microservices" | "Scale without downtime" |
| 功能罗列 | "Features: API, webhook, OAuth" | "Connects with everything you use" |
| 抽象承诺 | "Better productivity" | "Save 2 hours every day" |
| 内部术语 | "Deploy to your namespace" | "Go live in one click" |

## 案例研究

### PostClaw案例

**背景**: 社交媒体多平台发布工具

| 版本 | 标题 | 结果 |
|------|------|------|
| 原版 | "Publish on 13 platforms from one chat" | 2周40用户 |
| 失败版 | "Your own OpenClaw instance. For social media." | **0用户** |
| 优化版 | "Your social media. Done in 30 seconds." | 当晚8注册 |

**教训**: 流量不变，仅标题改变就导致转化率归零，证明文案的致命重要性。

## 工具推荐

- **A/B测试**: Google Optimize, Optimizely
- **用户行为分析**: Hotjar, FullStory
- **文案灵感**: ReallyGoodEmails, LandingFolio
- **标题分析**: CoSchedule Headline Analyzer

## 输出

应用此技能后，应产出：
1. 用户导向的标题（3个版本）
2. 三层信息架构的landing page文案
3. A/B测试计划
4. 转化率追踪表
