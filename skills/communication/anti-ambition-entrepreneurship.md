## 触发条件

- 创业初期，不知道从何开始
- 多次创业失败，需要改变策略
- 追求"改变世界的宏大愿景"导致 paralysis
- API工具/SaaS产品冷启动

---

## 执行步骤

### 1. 问题选择
找一个**你自己有痛点的具体小问题**
- ❌ 不要选"大市场"
- ✅ 选"我每天都遇到的这个麻烦"

### 2. 目标降级
第一个目标设为：
- ✅ "赚到第一块钱"
- ❌ 不是"月入过万"

### 3. 单点聚焦
- 选定一个产品后all in
- ❌ 不要并行多个项目
- 案例：Dmytro花了2年才搞清卖给谁

### 4. 用户深潜
花至少**6个月**深度理解用户
- 用户访谈
- 行为数据分析
- 痛点验证

### 5. 漏斗优化
用PostHog等工具追踪：
```
访客 → 注册用户 → 活跃用户 → 付费用户
```
每个环节优化转化率

### 6. 渠道实验
- 测试5-10个渠道
- 找到ROI最高的1-2个
- 案例：Reddit成为主要增长渠道

### 7. 定价实验
**混合定价模式**：
- 订阅制：保证基础收入
- 按量付费：收入上限随使用量增长
- 降低入门门槛，同时保证收入上限

## 代码/模板

### 最小可行产品(MVP)检查清单
```
□ 解决我自己的痛点
□ 第一版功能不超过3个
□ 48小时内可以上线
□ 有明确的付费路径
□ 可以衡量用户行为
```

### 漏斗追踪模板
```python
# 关键指标追踪
metrics = {
    'visitor_to_signup': 0,    # 访客→注册
    'signup_to_active': 0,     # 注册→活跃
    'active_to_paid': 0,       # 活跃→付费
    'monthly_churn': 0,        # 月流失率
    'ltv_cac_ratio': 0         # LTV/CAC比
}

# 优化目标：提升每个环节1% = 整体提升N%
```
