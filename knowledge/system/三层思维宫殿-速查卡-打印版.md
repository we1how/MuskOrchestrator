```

│                        【原则1】5-Why本质挖掘法                          │
├────────────────────────────────────────────────────────────────────────┤

┌────────────────────────────────────────────────────────────────────────┐

│ 怎么用：72小时内产出：1)行动清单 2)知识卡片 3)可执行代码 4)决策依据       │

│                       【原则3】10-10-10情绪冷却法                         │
├────────────────────────────────────────────────────────────────────────┤
│ 何时用：强烈情绪（愤怒/恐惧/兴奋），想要立即反应时                         │
│ 怎么用：等待10分钟，问自己：10分钟后？10个月后？10年后？这事还重要吗？      │
│ 标准：反应基于理性而非情绪                                               │
├────────────────────────────────────────────────────────────────────────┤
│ 检查清单：                                                              │
│ □ 我等待了至少10分钟吗？                                                │

│ 标准：每月解决1个系统性问题                                              │
├────────────────────────────────────────────────────────────────────────┤
│ 检查清单：                                                              │
│ □ 我今天记录了3个问题吗？                                               │
│ □ 我周末筛选了最有价值的问题吗？                                         │
│ □ 我月度解决了系统性问题吗？                                             │
```

4. 第三页（行为链）贴在电脑旁
